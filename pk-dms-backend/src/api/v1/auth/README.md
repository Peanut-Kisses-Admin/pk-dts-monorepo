# Auth API

Base path: `/api/v1/auth`

This module currently exposes login for the frontend.

## Endpoints

### `POST /login`

Authenticates a user by email and password.

Request body:

```json
{
  "email": "admin@document-tracking.com",
  "password": "admin123"
}
```

Validation:

- `email` must be a valid email
- `password` is required

Response:

```json
{
  "user": {
    "user_id": "1",
    "firstname": "Admin",
    "lastname": "User",
    "email": "admin@document-tracking.com",
    "role": {
      "role_id": "1",
      "role_name": "Administrator"
    }
  },
  "token": "session-1-1710000000000"
}
```

Notes:

- The password is never returned
- The returned `user` includes the role and its permissions
- The token is a session-style token generated by the API
